This page will list all actions for scripts.

Any parameter surrounded by square brackets is optional. Any parameter with the "constant" attribute means you have to write something fixed into it, you can't use a script variable. Any parameter with the "list" attribute means the word you pass in as an argument, as well as all words that come afterwards, are all a part of this parameter.

Common actions

Actions that can be used both in object scripts and in area scripts.

Script control

Do while

Starts a block of actions that can be looped over multiple times. The block starts after this action and ends before the matching end_do_while action.
After running the block once, if the condition at the end of the block (specified by the end_do_while action) is still true, then the script jumps back to the do_while action, and the whole process repeats.
The condition works just like how the if action works. Make sure the condition can eventually be false otherwise this will be an infinite loop!
This is similar to a while_do loop, except this type of loop always runs the block at least once and only then checks the condition, while that one has the condition at the start and so may end up never needing to run the block.

Syntax: do_while

Else

If the corresponding if action's check ends up being false, the script will run this else's block of actions. The block starts after this action and ends before the matching end_if action.

Syntax: else

Else if

Same as if you had an else action followed by an if action, except it doesn't enter a new level of depth. In order words, you only have one end_if for this sequence. So something like: if ... else_if ... else_if ... else_if ... else ... end_if. If you have an else in the sequence, it must come after any else_if. The condition works exactly like the one in the if action.

Syntax: else_if <left> <operator> <right>

left Same as the if action. Mandatory String
operator Same as the if action. Mandatory, constant String
right Same as the if action. Mandatory String

End do while

See do_while.

Syntax: end_do_while <left> <operator> <right>

left Same as the if action. Mandatory String
operator Same as the if action. Mandatory, constant String
right Same as the if action. Mandatory String

End for

See for.

Syntax: end_for

End for each

See for_each.

Syntax: end_for_each

End if

See if.

Syntax: end_if

End while do

See while_do.

Syntax: end_while_do

For

Starts a block of actions that can be looped over multiple times. The block starts after this action and ends before the matching end_for action.
The first time this for action is run, the variable <iterator_var_name> receives the default value of 1, and every other time it adds + 1 to the value. The block is looped over and over until the number is higher than <target_amount>, at which point the loop ends and the script continues from after the end_for action.
In other words, you can use this to loop a block of actions exactly <target_amount> times, and every iteration you can check the <iterator_var_name> variable to know what loop iteration you're on: 1 means the first loop, 2 means the second, etc.
In programming languages like C++ this is the same as for(int <iterator_var_name> = 1; <iterator_var_name> <= <target_amount>; <iterator_var_name>++).

Syntax: for <iterator_var_name> <target_amount> [<starting_amount>] [<jump>]

iterator_var_name Name of the variable that will control the iteration number. Even if you don't need the iterator variable, it still needs to be present so the script knows how to continue between one loop and the next. Careful that you don't use the same iterator variable when you have a loop inside another loop, or they'll compete for control of the variable! Mandatory, constant String
target_amount The loop ends after the iterator is past this number. Normally, this is the number of times you want the loop to run for. Mandatory Number
starting_amount Starting value for the iteration number. Optional, default: 1 Number
jump How much each iteration makes the iterator value jump. By default this is +1. You can use -1 to make it go backwards, +2 to make it skip every other number, etc. Optional, default: 1 Number

For each

Starts a block of actions that can be looped over multiple times. The block starts after this action and ends before the matching end_for_each action.
The first time this for_each action is run, the variable <iterator_var_name> receives the value of 1, and the variable <item_var_name> receives the value of the first item in the list. Every other time it adds + 1 to the iterator variable and set the item variable to the next item over. Once the list has been combed through, the loop ends and the script continues from after the end_for_each action.
In other words, you can use this to do something to each entry in a list. Be careful that you aren't changing the list as you're going through it or you might end up confused!

Syntax: for_each <iterator_var_name> <item_var_name> <list> [<list_delimiter>]

iterator_var_name Name of the variable that will control the iteration number. Even if you don't need the iterator variable, it still needs to be present so the script knows how to continue between one loop and the next. Careful that you don't use the same iterator variable when you have a loop inside another loop, or they'll compete for control of the variable! Mandatory, constant String
item_var_name Name of the variable that will hold what the current item is. Mandatory, constant String
list String representing the list of items. Mandatory String
list_delimiter The list delimiter. Optional, default: comma String

Goto

Orders the script to jump to wherever the given label is. The label must be in the same action block as this goto. You can use this to loop actions multiple times in a row by returning to the top of the loop.

Syntax: goto <label_name>

label_name Name of the label to jump to. Mandatory String

If

Only executes the next block of actions if the condition you specify is true.
Said block starts after this action and ends before the next matching else, else_if, or end_if action.
If the condition is false, the script jumps to the next matching else, else_if, or end_if action.
You can compare two things, but unless you want the result to always be the same, you'll probably want at least one of those things to be the contents of a variable.

Syntax: if <left> <operator> <right>

left First thing to compare. Mandatory String
operator How the two should be compared.
  • =: True if <left> matches <right>. Works with numbers or text.
  • !=: True if they don't match. Also works with numbers or text.
  • <: True if the number in <left> is less than the number in <right>.
  • >: Greater than.
  • <=: Less than or equal.
  • >=: Greater than or equal.
 Mandatory, constant String
right Second thing to compare. List, mandatory String

Label

Labels this point of the script with the given name. You can then use the goto action to force the script to go to this point at will. Each label is only accessible in the action block it belongs to.

Syntax: label <label_name>

label_name Name of the label. Should be unique within this block of actions. Mandatory, constant String

Set state

Instantly changes to the specified state. If there were other actions afterwards in this action's block, they will not be run.

Syntax: set_state <state>

state Internal name of the state. Mandatory String

While do

Starts a block of actions that can be looped over multiple times. The starts after this action and ends before the matching end_while_do action.
The block is only run if the condition at the start (specified by the while_do action) is true. If the block is run, then at the end the script returns to the while_do action, and the whole process repeats.
The condition works just like how the if action works. Make sure the condition can eventually be false otherwise this will be an infinite loop!
This is similar to a do_while loop, except this type of loop has the condition at the start and so may end up never needing to run the block, while that one always runs the block at least once and only then checks the condition.

Syntax: while_do <left> <operator> <right>

left Same as the if action. Mandatory String
operator Same as the if action. Mandatory, constant String
right Same as the if action. Mandatory String

Mathematics

Absolute number

Gets the absolute value of the given number. In other words, it converts a negative number into its positive version.

Syntax: absolute_number <destination_var_name> <number>

destination_var_name Name of the variable that will receive the final result. Mandatory, constant String
number Number to calculate. Mandatory Number

Calculate

Calculates a mathematical operation between two operand numbers. It makes sense to use a variable in at least one of the operands, otherwise you're just punching in a fixed number calculation that any household calculator could tell you about.

Syntax: calculate <destination_var_name> <left> <operator> <right>

destination_var_name Name of the variable that will receive the final result. Mandatory, constant String
left First operand. Mandatory Number
operator Mathematical operation.
  • +: Add both numbers.
  • -: Subtract the second number from the first.
  • *: Multiply both numbers.
  • /: Divide the first number by the second. A division by 0 results in a 0.
  • %: Modulo operation.
  • ^: Raise the first number to the power of the second.
 Mandatory, constant String
right Second operand. Mandatory Number

Ceil number

Gets the ceil of the given number. In other words, it rounds the number's decimal places up to an integer. Using this on a positive number like 6.3 returns 7, and on a negative number like -6.3 it returns -6; if you want to just get rid of the decimal part, see truncate_number.

Syntax: ceil_number <destination_var_name> <number>

destination_var_name Name of the variable that will receive the final result. Mandatory, constant String
number Number to ceil. Mandatory Number

Clamp number

Gets whatever <number> is, unless it goes under the lower bound or above the upper bound, in which case it stays at the number of that bound. In a way, this combines min_number and max_number.

Syntax: clamp_number <destination_var_name> <number> <lower_bound> <upper_bound>

destination_var_name Name of the variable that will receive the final result. Mandatory, constant String
number Number to clamp. Mandatory Number
lower_bound Lower allowed bound. Mandatory Number
upper_bound Upper allowed bound. Mandatory Number

Ease number

Gets the eased interpolation of the given number. In other words, it makes the number slow down as it approaches its destination, or speed up, or overshoot and then return, etc. As such, it's useful for animating things in interesting ways. The number should be between 0 (starting point) and 1 (ending point), and the output goes from 0 to 1 as well, though it can go over for effect. This means you can multiply whatever you need, like a distance, by the resulting number.

Syntax: ease_number <destination_var_name> <number> <method>

destination_var_name Name of the variable that will receive the final result. Mandatory, constant String
number Number to ease. Mandatory Number
method Easing method:
  • in: Eases as it goes in, then gradually goes out normally.
  • out: Gradually goes in normally, then eased as it goes out.
  • in_out: Eased as it goes in and also as it goes out.
  • in_back: Goes backwards before going in.
  • out_back: Overshoots at the end then finishes.
  • in_out_back: Combines in back with out back.
  • in_elastic: Springs backwards before going in.
  • out_elastic: Near the end, it overshoots and then springs to normal.
  • up_and_down: Goes up to 1, then back down to 0, in a sine-wave.
  • up_and_down_elastic: Goes up to 1, then down to 0, and wobbles around 0 for a bit.
 Mandatory, constant String

Floor number

Gets the floor of the given number. In other words, it rounds the number's decimal places down to an integer. Using this on a positive number like 6.3 returns 6, but on a negative number like -6.3 it returns -7; if you want to just get rid of the decimal part, see truncate_number.

Syntax: floor_number <destination_var_name> <number>

destination_var_name Name of the variable that will receive the final result. Mandatory, constant String
number Number to floor. Mandatory Number

Get angle

Gets the angle (in degrees) between two sets of coordinates. See also get_distance.

Syntax: get_angle <destination_var_name> <center_x> <center_y> <focus_x> <focus_y>

destination_var_name Name of the variable that will receive the final result. Mandatory, constant String
center_x X coordinate of the center point, the point that is facing towards the other one. Mandatory Number
center_y Y coordinate of the center point, the point that is facing towards the other one. Mandatory Number
focus_x X coordinate of the focus point, the point that the other one is facing towards. Mandatory Number
center_y Y coordinate of the focus point, the point that the other one is facing towards. Mandatory Number

Get angle clockwise difference

Gets the clockwise difference between two angles. In other words, how many degrees do we travel clockwise to get from the first angle to the second.

Syntax: get_angle_clockwise_difference <destination_var_name> <angle_1> <angle_2>

destination_var_name Name of the variable that will receive the final result. Mandatory, constant String
angle_1 Starting angle, in degrees. It can be negative or go beyond 360. Mandatory Number
angle_2 Ending angle, in degrees. It can be negative or go beyond 360. Mandatory Number

Get angle smallest difference

Gets the smallest difference between two angles. In other words, how many degrees do we travel clockwise or counterclockwise to get from the first angle to the second, whichever number is smaller.

Syntax: get_angle_smallest_difference <destination_var_name> <angle_1> <angle_2>

destination_var_name Name of the variable that will receive the final result. Mandatory, constant String
angle_1 First angle to check, in degrees. It can be negative or go beyond 360. Mandatory Number
angle_2 Second angle to check, in degrees. It can be negative or go beyond 360. Mandatory Number

Get coordinates from angle

Gets the X and Y coordinates that represent the specified angle and distance. Basically, imagine an imaginary point at coordinates 0,0. If you go in the specified angle, for the specified distance, you'll end up at the returned coordinates.

Syntax: get_coordinates_from_angle <x_destination_var_name> <y_destination_var_name> <angle> <distance>

x_destination_var_name Name of the variable that will receive the final X coordinate. Mandatory, constant String
y_destination_var_name Name of the variable that will receive the final Y coordinate. Mandatory, constant String
angle Angle to use, in degrees. It can be negative or go beyond 360. Mandatory Number
distance Distance to use. Mandatory Number

Interpolate number

Gets the linear interpolation of the given values. In other words, it gets a number that's somewhere between the given values. When the <input_number> matches <input_start>, the result matches <output_start>. And when it matches <input_end>, the result matches <output_end>. In-between input values result in in-between output values.

Syntax: interpolate_number <destination_var_name> <input_number> <input_start> <input_end> <output_start> <output_end>

destination_var_name Name of the variable that will receive the final result. Mandatory, constant String
input_number Input number. This gets compared against input_start and input_end. Mandatory Number
input_start Starting amount to compare the input number against. Mandatory Number
input_end Ending amount to compare the input number against. Mandatory Number
output_start Result for when the input number matches input_start. Mandatory Number
output_end Result for when the input number matches input_end. Mandatory Number

Syntax: max_number <destination_var_name> <first_number> <second_number>

destination_var_name Name of the variable that will receive the final result. Mandatory, constant String

second_number Second number. Mandatory Number

Sign number

Gets either -1 if the given number is negative, 1 if positive, or 0 if it's zero. This is useful if you want to turn a different positive number into the same sign (positive or negative) as the number in this action, by multiplying that one by whatever this action returns.

Syntax: sign_number <destination_var_name> <number>

destination_var_name Name of the variable that will receive the final result. Mandatory, constant String
number Number to sign. Mandatory Number

Truncate number

Gets the integer portion of the given number. For instance, if the number is 6.3, the result is 6. This works differently from floor_number and ceil_number because of negative numbers – floor_number on -6.3 will return -7 whereas truncate_number will return -6.

Syntax: truncate_number <destination_var_name> <number>

destination_var_name Name of the variable that will receive the final result. Mandatory, constant String
number Number to truncate. Mandatory Number

List management

Lists are just a string, inside a variable or not, where all the items are laid out and separated by a comma (or semicolon, or space). With some creative uses of these actions, you can edit sentences – they're just lists of words separated by a space!

Add list item

Adds a new item to a list. The new list is then placed inside of <destination_var_name>. If you want to create a new list with one item from scratch, you're better off using set_var <new_list_var> <first_item>. See also add_to_string.

Syntax: add_list_item <destination_var_name> <list> <new_item> [<item_number>] [<list_delimiter>]

destination_var_name Name of the variable that will receive the final result. Mandatory, constant String
list String representing the list of items. Mandatory String
new_item The new item to add. Mandatory String
item_number Position to add the item to, with "1" making it the new first item, "2" making it the new second item, etc. "0" means it will be added to the end of the list. Optional, default: 0 Number
list_delimiter The list delimiter. Optional, default: comma String

Get list item

Gets one of the items in a list.

Syntax: get_list_item <destination_var_name> <list> [<item_number>] [<list_delimiter>]

destination_var_name Name of the variable that will receive the final result. Mandatory, constant String
list String representing the list of items. Mandatory String
item_number Position to fetch the item from, with "1" retrieving the first item, "2" retrieving the second, etc. "0" means it will get the last item. Optional, default: 0 Number
list_delimiter The list delimiter. Optional, default: comma String

Get list item number

Checks the items in a list, and gets the number of the item you're searching for. Item number "1" means it's the first item in the list, "2" means the second, etc. If the item number returned is "0", that means the item is not on the list. If the item appears multiple times in the list, this will only obtain the number of the first time it shows up.

Syntax: get_list_item_number <destination_var_name> <list> <item_to_search> [<list_delimiter>]

destination_var_name Name of the variable that will receive the final result. Mandatory, constant String
list String representing the list of items. Mandatory String
item_to_search Item you're searching for. Mandatory String
list_delimiter The list delimiter. Optional, default: comma String

Get list size

Gets the amount of items in a list.

Syntax: get_list_size <destination_var_name> <list> [<list_delimiter>]

destination_var_name Name of the variable that will receive the final result. Mandatory, constant String
list String representing the list of items. Mandatory String
list_delimiter The list delimiter. Optional, default: comma String

Focused object management

Focus

Focuses on a given mob from here on out. A script can only focus on one mob at a time. See also unfocus.

Syntax: focus <target_mob>

target_mob The target mob. Mandatory String

Focus on ID

Focuses on the mob with the given ID from here on out. Use get_mob_info to obtain a mob's ID. If this is called with an ID of 0 or an ID that no mob has, nothing will happen.

Syntax: focus_on_id <mob_id>

mob_id ID number of the mob. Mandatory Number

Get focus var

Sets the variable <destination_var_name> of this mob to the same value as the variable <focused_mob_var_name> of the focused mob, if any.

Syntax: get_focus_var <destination_var_name> <focused_mob_var_name>

destination_var_name Name of the variable that will receive the final result. Mandatory, constant String
focused_mob_var_name Name of the variable of the focused mob that you want to read from. Mandatory, constant String

Set focus var

Sets the variable <focus_destination_var_name> of the focused mob to the value <value>.

Syntax: set_focus_var <focus_destination_var_name> <value>

focus_destination_var_name Name of the variable of the focused mob that you want to write to. Mandatory, constant String
value Value to write. Mandatory String

Unfocus

Loses focus on whatever object it had focus, if any.

Syntax: unfocus

Get mission metric

Gets some information about a mission metric.
Some metrics also need data about a number to check, like the "leaders in region" metric needing to know the region number. In those cases, <number_data> needs to specify the intended number.
Normally this action obtains the current value of a metric, but most metrics can obtain an automatic "target" value, like the "seconds left" metric using this to recommend to the total amount of seconds in the time limit. To obtain this information instead, use the <get_auto_target_instead> parameter.

Syntax: get_mission_metric <destination_var_name> <metric> [<number_data>] [<get_auto_target_instead>]

destination_var_name Name of the variable that will receive the final result. Mandatory, constant String
metric Metric data to obtain:
  • mob_group_cleared_mobs: Cleared mobs in a mob group. Needs the mob group number.
  • mob_group_health: Combined health of the mobs in a mob group. Needs the mob group number.
  • seconds_left: Seconds left in the time limit.
  • seconds_passed: Seconds passed in the mission.
  • leaders_in_region: Leaders inside an area region. Needs the region number.
  • living_pikmin: Pikmin currently alive in total.
  • pikmin_born: Pikmin born so far.
  • pikmin_lost: Pikmin lost so far.
  • leaders_lost: Leaders lost so far.
  • object_collection_points: Object collection points obtained.
  • treasure_collection_points: Treasure collection points obtained.
  • enemy_collection_points: Enemy collection points obtained.
  • enemy_defeat_points: Enemy defeat points obtained.
 Mandatory String
number_data If the metric requires some number data, specify it here. Optional, default: 1 Number
get_auto_target_instead If true, instead of getting the metric's current amount, gets the auto amount. Optional, default: false Boolean

Common data

List delimiter

Actions that deal with lists have a parameter that lets you pick the list's delimiter. This allows you to have lists in various formats to suit your needs. The delimiter is essentially what separates each of the items in the list. The possible values for the delimiter parameter are:

  • comma: Commas (,). The default.
  • semicolon: Semicolons (;). Good for when some of your items need to use commas themselves.
  • space: Spaces ( ). Good for treating a sentence as a list of words.

Target mob

Some actions require a mob to be selected as a target. Possible target types are:

  • self: The object that the script belongs to.
  • focus: The object that is currently focused. The action does nothing if none is focused.
  • trigger: The object that triggered the event. The action does nothing if this is not applicable.
  • link: The first linked object. The action does nothing if there is no linked object, or the mob has just spawned.
  • parent: The parent object. The action does nothing if there is no parent object, or the mob has just spawned.
